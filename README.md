## Desenvolvimento

Com Node.js 20.9 ou superior, execute `npm ci` e `npm run dev`.
Abra [localhost:3000](http://localhost:3000).

Para testar a versão de produção, execute `npm run build` e `npm start`.

Primeira atividade: Criei um site de um arquivo (HTML com CSS animado) com uma
promessa de desenvolvimento de jogo de forca e um pedido de doação (Pix).
